# How a content agency runs (the process this OS is built on)

The database follows the work. If your process is different, say so before the
Interview questions, because a different process changes the tables.

## 1. Onboarding (clients table, onboarding stage)
0 Paid → 10 Contract Sent → 20 Contract Signed → 30 Set-Up → 40 Call Booked → 50 Call Taken → 100 Onboarded.
Set-Up covers: the client's Slack channel, the shared folders (one for raw footage), the onboarding form, and a strategy brief.

## 2. Editing pipeline (the Editing pipeline board)
The client uploads raw footage → ready to edit → editing → internal review → amendments (bounce-back) →
client review → client changes (bounce-back) → ready to post → scheduled → posted.
One card is one video. The caption has its own status: to write, to review, done.

## 3. Reporting (daily and weekly numbers)
Posts published, views, followers, engagement rate and the top post, per client, per day and per week.

## 4. Everything else (the Tasks board)
Any one-off job for anyone. Stages: -1 Rejected (will not be done), 0 Backlog, 9 Blocked, 10 In Progress, 29 Amendments, 30 In Review, 100 Complete.
